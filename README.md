# alma-meme-watcher

Alma 插件：全网多源热梗监控与编译入库引擎。

持续追踪 B 站优质解梗/造梗 UP 主（首发支持 [**梗指南**](https://space.bilibili.com/94510621) `mid=94510621`，可插拔扩展更多 UP 主及其他平台数据源），提取音视频字幕、转写及热评精华，将网络流行语与新梗编译为面向 AI Agent 使用的高质量结构化词卡（包含使用场景、情绪极性、误用禁忌及出处链接），并增量同步至 Alma 的 `~/.config/alma/state/meme_radar.db` 本地词库。

## 设计原则与架构

1. **多源可插拔架构**：
   - 数据源层（`src/sources/`）：采用统一信封协议，支持接入 B 站多个 UP 主、社交媒体热搜、垂直黑话社区等不同渠道。
   - 编译提炼层（`src/compiler/`）：将嘈杂的视频/图文素材提炼为标准的 9 字段 Agent 词卡，确保具备准确性与语用安全边界。
   - 存储与检索引擎（`src/store/`）：基于 SQLite，支持精确+多别名自动归并、幂等同步、歧义拦截、TTL 自动衰减与事务回滚。
2. **作为 Alma 自主研发外环的自维护样板**：
   - 仓库日常由 Alma 负责监控、调度、编写 Issue、审查 PR 与版本迭代。
   - 插件运行时负责日常素材抓取与词条落盘，代码维护与数据流水线清晰解耦。
