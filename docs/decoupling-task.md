# 通用梗能力与社区解耦契约

## 当前职责

`alma-meme-watcher` 拥有词库、编译、入库、维护和公开检索。通用 `meme-use` 技能指导 Alma 按需查询与表达。社区技能拥有帖子正文、图片、楼层关系、账号核验、发送和操作回执。

社区常规读取交付原始详情，不自动查询词库，不附加 `knowledge`、`brief` 或 `tone`。Alma 读完社区内容后，可以为理解陌生表达调用通用查询。显式 `read knowledge --query` 保留为公开检索兼容入口。

表达尺度是通用 `playfulness`，沿用 Alma 配置根下的 `state/meme_tone.json` 和默认值 45。它是可选玩梗的上限，不是社区专属开关。0 仍允许明确的含义和出处解释。100 不要求玩梗，也不改变严肃求助的任务。用户纠正只修正本次对话，不自动改写生产词卡或尺度。

这些要求替代早期的社区专属尺度、读帖隐式 brief 和 tone 注入要求。

## 第一阶段交付边界

第一阶段提供通用技能、只读策略 `get`、严格整数策略 `set`，以及可预览、临时复制、显式应用和条件回滚的社区迁移工具。策略设置保留其他 JSON 对象键，拒绝丢弃损坏或非对象配置。

迁移只删除已识别的隐式词卡附加路径与死 helper。显式适配器绑定已安装插件的绝对路径。退休的表达和私有读取脚本转为公开 CLI 转发，不保留私有 SQL 或第二个策略写入器。运行中的 `meme_backfill_avoid.py` 保持字节不变。

社区发送、图片、账号、楼层关系、回执以及 state、runtime、context、admin 代码不改动。`lookup.mjs` 与公开词卡检索契约不改动。词库、种子、游标、模型提供方与维护流程不在本阶段改动范围内。

## 验收边界

便携测试使用仓库中的合成素材和临时配置根。安装源测试只操作临时复制树，运行实际提取的读取函数并比较保护代码哈希。常规读取需要零次隐式查询、零张附加词卡，同时保留正文、图片位置、楼层回复关系、账号核验和详情交付。

公开查询必须区分成功无命中与数据库故障。迁移必须验证计划与源文件、备份全部改动前像、支持重放和部分状态恢复，并在外来改动时拒绝覆盖。测试不能把源码文本匹配当成 Alma 自然语言行为验证。

实际安装、工具发现与全新 Alma 会话行为仍由安装闸门验收。步骤见 [社区迁移指南](integration-migration.md)。维护属于后续阶段；本契约不授权生产切换、模型请求或数据库写入。
